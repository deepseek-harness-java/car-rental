# AI 租车管家 · 使用说明

## 一、系统简介

本系统由两部分组成：

- **租车业务台**（p-app，端口 18104）：浏览器打开的看板页面，含运营看板、车辆实况、最新订单三个卡片，以及右侧 AI 管家对话窗。
- **AI 管家（rental-copilot）**：通过 DSH Java Native Plugin 注册进 Harness 的智能体，可调用 7 个业务工具，用自然语言完成查询与下单。

## 二、启动步骤

1. 启动 DSH Harness（8090，standalone）并配置模型。
2. 安装并激活插件 `rental-copilot`（见 README 快速开始）。
3. 启动业务应用：`java -Dserver.port=18104 -jar p-app/target/p-app-1.0.0-SNAPSHOT.jar`。
4. 浏览器访问 `http://127.0.0.1:18104`。

## 三、能做什么（含示例话术）

### 1. 车辆查询（car_list）
> "现在有哪些车可以租？一家三口出游推荐哪台？"

返回 6 台车的车型/车牌/门店/日租价/押金/挡位/座位/状态；可按门店（机场店/市中心店/高铁站店）或状态（可租/已租出/维保中）过滤，并按场景给推荐。

### 2. 门店查询（store_list）
> "三家门店分别在哪、几点营业？"

返回门店地址、营业时间与各店当前可租数。

### 3. 价目查询（price）
> "商务MPV 租 3 天多少钱？"

价目：经济轿车 ¥168 / 舒适SUV ¥298 / 新能源 ¥258 / 商务MPV ¥598 / 豪华轿车 ¥888（元/天），并报押金（¥2000–¥8000）与车型说明，多项自动算总价。

### 4. 下单租车（rent）
> "我是赵小明，手机13812345678，租C05豪华轿车2天"

规则：
- 下单前管家会**复述车辆/租期/租金/押金/门店**请你确认；
- 仅"**可租**"状态可下单，已租出/维保中会被拦截并给替代建议；
- 成功后返回**订单号**（O9001 格式）、租金、押金与取车门店、取还车时间。

### 5. 订单查询（order_info）
> "查一下订单 O9003"

返回车辆、取还车时间、租期、金额与状态（待取车/在租/已还车）。

### 6. 维保一览（maintenance）
> "现在有车在维保吗？什么时候恢复？"

返回维保中车辆的牌号、项目、开始时间与预计恢复时间，并给同车型替代建议。

### 7. 运营看板（stats）
> "今天车队运营情况怎么样？"

返回总车辆/可租/已租出/维保中/在租订单/出租率/分车型余量，并给调度建议（如满店分流、主推车型）。

## 四、安全与边界

- 保险责任、事故处理**只转述条款说明**，不自行承诺赔付；
- 数据全部来自工具返回，管家不编造车况与价格；
- 下单涉及资金（租金+押金），必须先复述要素并获客户确认；
- 押金在还车验车后退还，管家会主动提示。

## 五、常见问题

**Q：提示车辆"不可下单"？**
车辆当前为已租出或维保中。可让管家推荐同车型其他车或其他门店。

**Q：提示"正在执行上一条消息"？**
上一个请求还在处理。可等几秒，或调用 `POST /api/agent/rental-copilot/cancel` 后重试。

**Q：插件激活失败 / 调用了旧工具？**
若曾用同名 pluginId 装过旧 jar，先卸载再重装：
`POST /api/harness/plugins/rental-copilot/uninstall`，重新 install + activate，并重启 DSH 以清空会话缓存。
